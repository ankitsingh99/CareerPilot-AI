- **Flexible shifts / 5 days / 10-12 hr workday**: Yes
- **Business Travel**: Yes (up to 100%)
- **Career Break**: No
- **Work Authorization**: Authorized to work in India (Yes)
- **Portfolio URL**: Link to LinkedIn or public resume URL
